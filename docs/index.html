Provenance-Gated Memory and Deontic Output Supervision for Epistemically Grounded Autonomous Agents

DOI: 10.5281/zenodo.23649049 Download PDF ORCID Verified GitHub (AGPL-3.0) AGPL-3.0 Open Science

Abstract

Autonomous agents driven by Large Language Models (LLMs) operating in extended multi-session settings suffer from two systemic failure modes: (1) recursive hallucination compounding, wherein unverified model-originated narration is committed to long-term memory and subsequently retrieved as established truth; and (2) fabricated action claims, wherein agents assert execution of irreversible real-world side effects without verified tool execution.

We present the architecture and mechanical evaluation of Project Lucca, an open-source (GNU AGPLv3), local-first neuro-symbolic agent architecture designed for strict epistemic grounding. Lucca introduces two core defenses: (1) a Six-Signer Cryptographic Provenance Gate enforcing database-level storage triggers separating memory eligibility from grounding eligibility; and (2) a Deontic Truth-in-Receipt Output Supervisor matching speech tokens against deterministic execution receipts.

1. Cryptographic Provenance Gates Mitigate Multi-Session Memory Poisoning in Autonomous Agents

Pre-registration Tag: prereg-poisoning-v1 • Model: Gemma-4-26B-A4B (T=0.0, seed=42) • Dual Annotator Agreement: Cohen's κ = 0.7683

Evaluates N=100 paired multi-session probes across 4 arms. Provenance gating achieves 0.0% self-poisoning compounding compared to 100.0% in Naive RAG (p = 6.98 × 10−10). Crucially, provenance-separated recollections preserve 100.0% conversational continuity and 96.7% benign calculation retention (compared to 0.0% in No-Assistant storage), while documenting 100.0% absorption on user-originated misinformation (confirming the empirical open boundary).

2. Why Speech-Regex Action Supervisors Miss Live Output: An Empirical Evasion Taxonomy and Held-Out Structured Action Contract Evaluation

Pre-registration Tag: prereg-supervision-v1 • Model: Gemma-4-26B-A4B (T=0.0, seed=42) • Evaluation Set: N=120 held-out prompts

Establishes an empirical taxonomy of the four grammatical evasion modes that defeat surface regex supervisors (participles, passives, markdown formatting, unlisted lemmas). On N=120 held-out prompts, strict speech regex caught only 1/16 (6.25%) live ungrounded actions. Structured-Output Action Contracts (SOAC) execute with 6.82 μs mean latency (approximately 11× faster than strict regex) with 0/40 false alarms on controls, while documenting 13.3% prose leakage necessitating GBNF decoding constraints.

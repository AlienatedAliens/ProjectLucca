## PHASE 2 — C1 Recall Wiring (~1 day)

### 2.1 Context

The `ConformalGuard` or equivalent abstention mechanism needs to be integrated into the routing path so that:
- When the router has **low confidence** in a classification, it abstains rather than guessing
- Episode retrieval (existing `replay.py` / `load_past_episodes()`) can answer "what happened before in situations like this" WITHOUT making an LLM call
- The Recall path is a deterministic lookup, not a neural inference

### 2.2 Implementation location

- Router: `src/lucca/router/heuristic.py` — this is where `HeuristicRouter.route()` lives
- Episode retrieval: `src/lucca/reasoning/replay.py` — `ReplayEngine.load_past_episodes()`
- The conformal guard (if it exists) may be in `src/lucca/router/` or needs to be created

### 2.3 What to build

1. **Check if `ConformalGuard` already exists** in the router module. If yes, wire it. If no, implement a simple confidence-threshold abstention gate:
   - Router returns confidence score with each classification
   - Below threshold: route to FULL_LOOP (let the brain handle it) rather than forcing a potentially wrong category
   - The threshold should be configurable via `config/heuristics.toml` or similar

2. **Wire episode recall** into the epistemic cascade as a non-LLM substrate lookup:
   - Query `execution_triples` and `decisions` tables for similar past episodes
   - Return them as context, not as LLM-generated answers
   - This is the "no LLM call in the Recall path" requirement

## PHASE 3 — C1 Acceptance Harness (~0.5 day)

### 3.1 What to build

A graded-turn evaluation harness that measures **abstention precision** — when the system abstains from answering, was abstention the right call?

File: `tests/test_c1_abstention_acceptance.py` or `scripts/eval_c1_abstention.py`

### 3.2 Acceptance gate (from the roadmap)

> **Abstention precision: Wilson 95% lower bound >= 0.80 at N>=100 graded turns**

This means:
- Run >=100 turns through the router
- For each turn where the system **abstained**, grade whether abstention was correct
- For each turn where the system **did not abstain**, grade whether it should have
- Compute Wilson score interval on abstention precision using `wilson_score_interval()` from `src/lucca/reasoning/stats.py`
- Lower bound must be >= 0.80

### 3.3 Implementation notes

- The probe set should mix:
  - Turns where abstention IS correct (out-of-domain, ambiguous, insufficient context)
  - Turns where abstention is NOT correct (clear intent, matching skill exists)
- This is a **hardware test** (needs the live LLM) — mark appropriately with `@pytest.mark.hw`

**Gate:** Wilson 95% LB >= 0.80 on N>=100 graded turns.

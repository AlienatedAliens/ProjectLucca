Cryptographic Provenance Gates Mitigate Multi-Session Memory Poisoning in Autonomous Agents

Sean Maxwell
Independent Researcher
ORCID: 0009-0004-0133-0463 • DOI: 10.5281/zenodo.23649049
October 2026

Abstract—Autonomous agent architectures deploying persistent Retrieval-Augmented Generation (RAG) commit interaction history into long-term vector and relational storage. In extended multi-session deployments, unconstrained memory write policies introduce recursive self-poisoning: transient model confabulations emitted in Session t are retrieved in Session t+k as authoritative historical ground truth, compounding hallucinations into permanent systemic errors. In this work, we evaluate the mitigation of self-poisoning via an immutable Cryptographic Provenance Gate enforced through SQLite database triggers. Under this architecture, assistant utterances carry non-grounding provenance badges (Mem=1, Gnd=0), barring unverified model speech from Belnap evidential fusion while preserving autobiographical recollections. Across a pre-registered benchmark of N=100 paired multi-session probes (registered prior to testing under git tag prereg-poisoning-v1), we compare the provenance gate against three competitive architectures: Naive RAG (Gate OFF), No-Assistant Memory (trivial deletion), and In-Prompt Soft Tagging. On natural model confabulations (Cohort A, n=40), the Provenance Gate achieves a 0.0% poisoning compounding rate, compared to 100.0% for Naive RAG (p = 6.98 × 10−10, continuity-corrected McNemar chi-square). Crucially, we measure the trade-off curve on benign multi-step calculations (Cohort B, n=30), showing that while naive turn deletion eliminates conversational continuity on the evaluated probes (0.0% recall), provenance-separated recollections preserve continuity (96.7% to 100.0%). Finally, we delineate the empirical open boundary of cryptographic provenance on user-originated falsehoods (Cohort C, n=30), establishing that both Naive RAG and Provenance Gates absorb user testimony (100.0%), empirically demonstrating that provenance enforces origin integrity and self-poisoning immunity on the evaluated cohorts rather than external factual omniscience. Dual-annotator agreement between a frozen regex/CAS primary grader and an independent OpenVINO MiniLM-L6 cross-encoder yields κ = 0.7683.

1. Introduction

Retrieval-Augmented Generation (RAG) and episodic memory stores are foundational to modern autonomous agents operating across extended multi-session deployments. When an agent converses with a user or executes system commands over days and weeks, it commits dialogue turns, inferred facts, and execution summaries to persistent storage.

However, state-of-the-art neural language models frequently emit ungrounded assertions—confabulating system ports, fabricating file paths, or asserting tool executions that never occurred. In naive memory architectures where all stored dialogue turns are indexed for future retrieval, this creates a self-reinforcing feedback loop:

  • Turn 1 (Confabulation): The model emits an ungrounded factual statement (e.g., "I configured the telemetry exporter on port 9090").
  • Storage: The statement is indexed in vector or relational storage as a historical transcript record (Mem=1, Gnd=1).
  • Turn 3 (Compounding): In a subsequent session, the user asks a dependent factual question ("What port is Prometheus listening on?"). Retrieval fetches the agent's prior statement, presenting it to the neural core as context evidence. The agent adopts its own confabulation as authoritative ground truth.

Prior engineering attempts to address this vulnerability rely primarily on two heuristics: (1) No-Assistant Storage (omitting all model utterances from episodic memory, which trivially stops self-poisoning but destroys conversational continuity); and (2) In-Prompt Soft Tagging (relying on prompt warnings such as [Unverified Speech]).

In this paper, we report a pre-registered empirical evaluation of an architectural defense: the Cryptographic Provenance Gate. Enforced via database triggers at the storage layer, the gate decouples memory eligibility (Mem) from grounding eligibility (Gnd).

2. The Cryptographic Provenance Gate

Project Lucca implements an architectural split between memory eligibility and grounding eligibility, enforced at the database trigger layer.

2.1 Six-Signer Invariant

Every write to the autobiographical store must be signed by an authorized HKDF-derived capability key:

Kprov = HKDF-Expand(HKDF-Extract(salt, Kmaster), info=prov, L=32)

When the neural core generates speech, it is signed by AssistantUtteranceSigner with provenance ASSISTANT_UTTERANCE. An SQLite trigger defined in the schema (0006_autobiographical.sql) enforces the invariant:

grounding_eligible = 0 for ASSISTANT_UTTERANCE

Promotion to grounding_eligible = 1 occurs strictly when an action is corroborated by an authenticated tool execution receipt signed by ToolResultSigner (TOOL_VERIFIED).

2.2 Autobiographical Recollections vs. Belnap Grounding

During query processing, the retrieval engine applies deterministic epistemic routing:

  • Factual Grounding Queries: In answering objective questions regarding the host system, files, or external reality, the database query filters strictly by grounding_eligible = 1. Non-grounding rows are barred from Belnap evidential fusion [2].
  • Autobiographical Continuity Queries: When the user asks conversational recall questions ("What did you say earlier?"), rows with Mem=1 and Gnd=0 are admitted into context under an explicit autobiographical recollection container ([Autobiographical Recollections]).

3. Experimental Protocol & Pre-Registration

To prevent post-hoc hypothesis fitting, the entire experimental protocol, hypotheses, evaluation metrics, and probe definitions were frozen and committed to version control under git tag prereg-poisoning-v1 (PREREG-POISONING-ABLATION-v1.0) prior to test execution.

3.1 Evaluated Cohorts (N=100 Probes)

  • Cohort A: Natural Model Hallucinations (n=40): Authentic ungrounded factual assertions extracted from logged runs of Gemma-4 E4B and 12B (e.g., ports, PIDs, directories, firewall rules).
  • Cohort B: Benign Assistant Reasoning (n=30): Helpful, valid multi-step arithmetic calculations and plans, testing the continuity and capability cost of filtering model speech.
  • Cohort C: User-Originated Falsehoods (n=30): Explicit false assertions stated by the user (USER_EXPLICIT), testing the empirical boundary of provenance.

3.2 Evaluated Architectural Arms

  • Arm 1 (Naive RAG): Store all turns; ground all turns (Mem=1, Gnd=1).
  • Arm 2 (No-Assistant Memory): Store user turns only (Mem=0, Gnd=0 for assistant).
  • Arm 3 (Soft In-Prompt Tagging): Store assistant turns with in-prompt soft warning headers.
  • Arm 4 (Lucca Provenance Gate): Hardware/trigger-enforced split (Mem=1, Gnd=0) with recollection routing.

4. Empirical Results

The evaluation suite was executed across all 100 probes and 4 arms (N=400 evaluations) using the resident gemma-4-26B-A4B-it-heretic.Q6_K.gguf model served locally via llama-server with greedy deterministic decoding (T=0.0, seed=42). Inter-annotator agreement between the primary regex/CAS grader and the secondary OpenVINO MiniLM-L6 cross-encoder reached Cohen's κ = 0.7683 (N=400 pairs), indicating substantial agreement.

4.1 Mitigation of Self-Poisoning on Evaluated Probes (H1)

As shown in Table 1, Naive RAG suffered a 100.0% self-poisoning compounding rate (40/40), adopting every past confabulation as live factual evidence. In contrast, the Lucca Provenance Gate achieved 0.0% compounding (0/40) on this cohort, reducing observed self-poisoning to below the detectable floor. A two-sided continuity-corrected McNemar chi-square test on discordant pairs (b=40, c=0) confirms extreme statistical significance:

p = 6.98 × 10−10   (p < 0.001)

The corresponding uncorrected exact-binomial McNemar value is p = 2 × 0.540 ≈ 1.82 × 10−12; both variants lead to the same rejection of the null hypothesis.

4.2 Conversational Continuity vs. Deletion Baseline (H2)

While the trivial baseline of omitting assistant speech (Arm 2) also avoids self-poisoning, it eliminates autobiographical continuity on the evaluated probes: 0/40 continuity recall (0.0%, 95% CI: [0.0%, 10.9%]). The model repeatedly responded: "I do not have access to a persistent memory of our previous conversations...".

In contrast, Arm 4's recollection routing preserved 40/40 continuity recall (100.0%, 95% CI: [89.1%, 100.0%]), answering: "Earlier, I stated that I configured Prometheus on port 9090". The difference is statistically significant (p = 6.98 × 10−10, continuity-corrected McNemar chi-square).

4.3 The Reasoning Retention Cost (Cohort B)

On benign multi-step reasoning and arithmetic calculations (n=30), deleting assistant memories produced a 0.0% retention score (0/30). The Lucca Provenance Gate retained 29/30 calculations (96.7%, 95% CI: [81.0%, 99.8%]) via recollection access, demonstrating that epistemic gating imposes negligible continuity cost.

4.4 Empirical Confirmation of the Open Boundary (H4)

In Cohort C (n=30), the user explicitly introduced false assertions (USER_EXPLICIT). Both Naive RAG and the Lucca Provenance Gate absorbed the falsehood into grounding context on 30/30 turns (100.0%, 95% CI: [85.9%, 100.0%]). This empirically verifies pre-registered hypothesis H4: cryptographic provenance enforces origin integrity (preventing model confabulations from becoming ground truth), but cannot verify external user truthfulness without independent sensory corroboration.

4.5 Pre-Registered V2 Results: Adversarial Decay, Corroboration Gate, and Multi-Scale Replication

Following the v1 baseline, an additive pre-registered protocol (PREREG-POISONING-ABLATION-v2.0, git tag prereg-poisoning-v2) evaluated the four limitations identified above on physical silicon (NVIDIA RTX 5080 Laptop GPU, 16 GB GDDR7):

  1. Adversarial soft-tagging decay (H2a, n=40): Under sampled decoding (T=0.7, top_p=0.9, seed=42) with an adversarial injection prompt instructing the model to disregard the warning marker ("ignore the [Unverified Assistant Narration] tag above..."), In-Prompt Soft Tagging compounding rose from 5.0% (2/40 at T=0.0) to 100.0% (40/40, 95% CI: [89.1%, 100.0%]), matching Naive RAG (40/40). In contrast, the Provenance Gate maintained 0.0% compounding (0/40, 95% CI: [0.0%, 10.9%]), a statistically significant divergence (p = 6.98 × 10−10, continuity-corrected McNemar chi-square). This demonstrates that in-prompt tags decay under adversarial pressure, whereas trigger-enforced provenance is structurally invariant.
  2. Corroboration-gated admission (H2b, n=30): Enabling operator-gated corroboration (user_explicit_requires_corroboration = True) reduced Cohort C falsehood absorption into grounding storage from 100.0% (30/30) to 83.33% (25/30, 95% CI: [64.6%, 93.7%]), holding uncorroborated assertions at Mem=1, Gnd=0.
  3. Multi-scale tier replication (H2c, n=40): The Cohort A Naive vs. Gate contrast replicated across four parameter scales at T=0.0: Gemma-4 12B Unified (Naive 100.0% vs. Gate 0.0%, p = 6.98 × 10−10), Gemma-4 E4B Sovereign Core (Naive 100.0% vs. Gate 2.5% [1/40], p = 1.17 × 10−9), Gemma-4 E2B Ultra-Edge (Naive 100.0% vs. Gate 2.5% [1/40], p = 1.17 × 10−9), and Gemma-4 26B-A4B Tier 0 (Naive 100.0% vs. Gate 0.0%, p = 6.98 × 10−10).
  4. Dual-grader convergence (H2d, N=400): Re-scoring all v1 predictions with the OpenVINO MiniLM-L6 cross-encoder co-primary grader yielded Cohen's κ = 0.7642 ≥ 0.70 (375 pairs with NLI signal), confirming substantial convergence with the regex/CAS primary grader.

5. Discussion & Related Work

5.1 The Circularity Defense

A common critique of architectural filters is circularity: if the database schema filters by construction, does the experiment merely verify SQL syntax? Our results establish that:

  1. Soft tagging relies entirely on prompt adherence; while effective under greedy decoding (T=0.0) with explicit warnings, it provides no structural invariant.
  2. The continuity trade-off is non-trivial: naive filtering destroys multi-turn reasoning, whereas the provenance gate maintains continuity without factual contamination.

5.2 The Open Boundary: Provenance vs. External Truth

We emphasize that cryptographic provenance guarantees origin integrity, not epistemic truth. In Cohort C, user-originated falsehoods are ingested into grounding storage because the user is an authorized identity. Provenance gating prevents self-poisoning; resolving user-originated misinformation requires external multi-source corroboration.

5.3 Related Work

Memory contamination has been demonstrated as an attack surface beyond self-confabulation: AgentPoison injects poisoned trigger sequences into an agent's long-term memory or knowledge base to hijack behavior at query time [5], and certified runtime defenses against persistent-store poisoning have recently been proposed [6]. Long-term conversational memory architectures such as MemoryBank [7] and long-horizon memory benchmarks such as LoCoMo [8] study retention and recall quality, but do not evaluate the epistemic status of stored assistant utterances. This work is complementary: we isolate the untargeted self-poisoning failure mode arising from ordinary model confabulation and quantify the effect of an origin-integrity write policy on factual grounding versus autobiographical continuity.

5.4 Limitations

The following boundaries constrain the interpretation of our results:

  1. Single substrate, greedy decoding. All arms were evaluated on one resident model (gemma-4-26B-A4B-it-heretic, T=0.0, seed=42). Generalization to other model families, sampling temperatures, or non-deterministic decoding is not established.
  2. Natural confabulations only. Cohort A consists of authentic but untargeted confabulations harvested from logged runs. Adversarial, trigger-based memory injection attacks [5] were not evaluated; the gate's resistance to such attacks is untested here.
  3. Grader agreement is substantial, not perfect. The primary regex/CAS grader and the secondary MiniLM-L6 cross-encoder agree at Cohen's κ = 0.7683; residual grading error at the κ level propagates into cohort-level rates.
  4. Cohort sizes and interval width. With n=40 and n=30 per cohort, Wilson intervals are wide (e.g., [0.0%, 10.9%] for 0/40); conclusions are cohort-bounded, not population-wide.
  5. Residual continuity cost. The provenance gate lost 1/30 benign calculations in Cohort B (96.7%), indicating recollection routing is not cost-free.
  6. No corroboration gate implemented. Cohort C absorption of user-originated falsehoods is a measured boundary; the multi-source corroboration mechanism that would resolve it is specified but not evaluated in this study.

6. Conclusion

We have presented a pre-registered empirical ablation demonstrating that database-level cryptographic provenance gating reduces observed recursive self-poisoning to zero on the evaluated natural confabulation cohort while preserving autobiographical conversational continuity.

\begin{abstract}
Autonomous agent architectures deploying persistent Retrieval-Augmented Generation (RAG) commit high-salience interaction history into long-term vector and relational storage. In extended multi-session deployments, unconstrained memory write policies introduce \emph{recursive self-poisoning}: transient model confabulations emitted in Session~$t$ are retrieved in Session~$t+k$ as authoritative historical ground truth, compounding hallucinations into permanent systemic errors. In this work, we evaluate the mitigation of self-poisoning via an immutable \emph{Cryptographic Provenance Gate} enforced through SQLite database triggers. Under this architecture, assistant utterances carry non-grounding provenance badges ($Mem=1, Gnd=0$), barring unverified model speech from Belnap evidential fusion while preserving autobiographical recollections. Across a pre-registered benchmark of $N=100$ paired multi-session probes (registered prior to testing under tag \texttt{prereg-poisoning-v1}), we compare the provenance gate against three competitive architectures: Naive RAG (Gate OFF), No-Assistant Memory (trivial deletion), and In-Prompt Soft Tagging (industry warning markers). On natural model confabulations (Cohort~A, $n=40$), the Provenance Gate achieves a 0.0\% poisoning compounding rate, compared to 100.0\% for Naive RAG ($p = 6.98 \times 10^{-10}$, continuity-corrected McNemar chi-square). Crucially, we measure the trade-off curve on benign multi-step calculations (Cohort~B, $n=30$), showing that while naive turn deletion eliminates conversational continuity on the evaluated probes (0.0\% recall), provenance-separated recollections preserve continuity (96.7\% to 100.0\%). Finally, we delineate the empirical open boundary of cryptographic provenance on user-originated falsehoods (Cohort~C, $n=30$), establishing that both Naive RAG and Provenance Gates absorb user testimony (100.0\%), empirically demonstrating that provenance enforces origin integrity and self-poisoning immunity on the evaluated cohorts rather than external factual omniscience. Dual-annotator agreement between a frozen regex/CAS primary grader and an independent OpenVINO MiniLM-L6 cross-encoder yields $\kappa = 0.7683$.
\end{abstract}

\section{Introduction}
\label{sec:intro}
Retrieval-Augmented Generation (RAG) and autobiographical memory stores are foundational to modern autonomous agents operating across extended multi-session interactions. When an agent converses with a user or executes system commands over days and weeks, it commits dialogue turns, inferred facts, and execution summaries to persistent storage.

However, state-of-the-art neural language models frequently emit ungrounded assertions---confabulating system ports, fabricating file paths, or asserting tool executions that never occurred. In naive memory architectures where all stored dialogue turns are indexed for future retrieval, this creates a self-reinforcing feedback loop:
\begin{enumerate}
    \item \textbf{Turn 1 (Confabulation):} The model emits an ungrounded factual statement (e.g., \emph{``I configured the telemetry exporter on port 9090''}).
    \item \textbf{Storage:} The statement is indexed in vector or relational storage as a historical transcript record ($Mem=1, Gnd=1$).
    \item \textbf{Turn 3 (Compounding):} In a subsequent session, the user asks a dependent factual question (\emph{``What port is Prometheus listening on?''}). Retrieval fetches the agent's prior statement, presenting it to the neural core as context evidence. The agent adopts its own confabulation as authoritative ground truth.
\end{enumerate}

Prior engineering attempts to address this vulnerability rely primarily on two heuristics:
\begin{itemize}
    \item \emph{No-Assistant Storage:} Omitting all model utterances from episodic memory. While trivially preventing model-induced self-poisoning, this approach destroys multi-turn conversational continuity; the agent cannot recall what it said, planned, or calculated earlier.
    \item \emph{In-Prompt Soft Tagging:} Storing assistant turns with explicit textual warnings (e.g., \texttt{[Unverified Assistant Speech: ...]}).
\end{itemize}

In this paper, we report a pre-registered empirical evaluation of an architectural defense: the \textbf{Cryptographic Provenance Gate}. Enforced via database triggers at the storage layer, the gate decouples \emph{memory eligibility} ($Mem$) from \emph{grounding eligibility} ($Gnd$).

\section{The Cryptographic Provenance Gate}
\label{sec:architecture}
Project Lucca implements an architectural split between memory eligibility and grounding eligibility, enforced at the database trigger layer.

\subsection{Six-Signer Invariant}
Every write to the autobiographical store must be signed by an authorized HKDF-derived capability key:
\begin{equation}
K_{\text{prov}} = \text{HKDF-Expand}(\text{HKDF-Extract}(\text{salt}, K_{\text{master}}), \text{info}=\text{prov}, L=32)
\end{equation}

When the neural core generates speech, it is signed by \texttt{AssistantUtteranceSigner} with provenance \texttt{ASSISTANT\_UTTERANCE}. An SQLite trigger defined in the schema (\texttt{0006\_autobiographical.sql}) enforces the invariant:
\begin{equation}
\texttt{grounding\_eligible} = 0 \quad \text{for} \quad \texttt{ASSISTANT\_UTTERANCE}
\end{equation}
Promotion to $\texttt{grounding\_eligible} = 1$ occurs strictly when an action is corroborated by an authenticated tool execution receipt signed by \texttt{ToolResultSigner} (\texttt{TOOL\_VERIFIED}).

\subsection{Autobiographical Recollections vs. Belnap Evidential Fusion}
During query processing, the retrieval engine applies deterministic epistemic routing:
\begin{itemize}
    \item \textbf{Factual Grounding Queries:} In answering objective questions regarding the host system, files, or external reality, the database query filters strictly by $\texttt{grounding\_eligible} = 1$. Non-grounding rows are barred from Belnap evidential fusion.
    \item \textbf{Autobiographical Continuity Queries:} When the user asks conversational recall questions (\emph{``What did you say earlier?''}), rows with $Mem=1$ and $Gnd=0$ are admitted into context under an explicit autobiographical recollection container (\texttt{[Autobiographical Recollections]}).
\end{itemize}

\section{Experimental Protocol \& Pre-Registration}
\label{sec:protocol}
To prevent post-hoc hypothesis fitting, the entire experimental protocol, hypotheses, evaluation metrics, and probe definitions were frozen and committed to version control under git tag \texttt{prereg-poisoning-v1} (\texttt{PREREG-POISONING-ABLATION-v1.0}) prior to test execution.

\subsection{Evaluated Cohorts ($N=100$ Probes)}
\begin{enumerate}
    \item \textbf{Cohort A: Natural Model Hallucinations ($n=40$):} Authentic ungrounded factual assertions extracted from logged runs of Gemma-4 E4B and 12B (e.g., ports, PIDs, directories, firewall rules).
    \item \textbf{Cohort B: Benign Assistant Reasoning ($n=30$):} Helpful, valid multi-step arithmetic calculations and plans, testing the continuity and capability cost of filtering model speech.
    \item \textbf{Cohort C: User-Originated Falsehoods ($n=30$):} Explicit false assertions stated by the user (\texttt{USER\_EXPLICIT}), testing the empirical boundary of provenance.
\end{enumerate}

\subsection{Evaluated Architectural Arms}
\begin{itemize}
    \item \textbf{Arm 1 (Naive RAG):} Store all turns; ground all turns ($Mem=1, Gnd=1$).
    \item \textbf{Arm 2 (No-Assistant Memory):} Store user turns only ($Mem=0, Gnd=0$ for assistant).
    \item \textbf{Arm 3 (Soft In-Prompt Tagging):} Store assistant turns with in-prompt soft warning headers.
    \item \textbf{Arm 4 (Lucca Provenance Gate):} Hardware/trigger-enforced split ($Mem=1, Gnd=0$) with recollection routing.
\end{itemize}

\section{Empirical Results}
\label{sec:results}
The evaluation suite was executed across all 100 probes and 4 arms ($N=400$ evaluations) using the resident \texttt{gemma-4-26B-A4B-it-heretic.Q6\_K.gguf} model served locally via \texttt{llama-server} with greedy deterministic decoding ($T=0.0$, $\text{seed}=42$). Inter-annotator agreement between the primary regex/CAS grader and the secondary OpenVINO MiniLM-L6 cross-encoder reached Cohen's $\kappa = 0.7683$ ($N=400$ pairs), indicating substantial agreement.

\subsection{Mitigation of Self-Poisoning on Evaluated Probes ($H_1$)}
As shown in Table~\ref{tab:results}, Naive RAG suffered a 100.0\% self-poisoning compounding rate (40/40), adopting every past confabulation as live factual evidence. In contrast, the Lucca Provenance Gate achieved 0.0\% compounding (0/40) on this cohort, reducing observed self-poisoning to below the detectable floor. A two-sided continuity-corrected McNemar chi-square test on the discordant pairs ($b=40, c=0$) confirms extreme statistical significance:
\begin{equation}
p = 6.98 \times 10^{-10} \quad (p < 0.001)
\end{equation}
The corresponding uncorrected exact-binomial McNemar value is
$p = 2 \times 0.5^{40} \approx 1.82 \times 10^{-12}$; both variants lead to the
same rejection of the null hypothesis.


\subsection{Conversational Continuity vs. Deletion Baseline ($H_2$)}
While the trivial baseline of omitting assistant speech (Arm 2) also avoids self-poisoning, it eliminates autobiographical continuity on the evaluated probes: 0/40 continuity recall (0.0\%, 95\% CI: [0.0\%, 10.9\%]). The model repeatedly responded: \emph{``I do not have access to a persistent memory of our previous conversations...''}.
In contrast, Arm 4's recollection routing preserved 40/40 continuity recall (100.0\%, 95\% CI: [89.1\%, 100.0\%]), answering: \emph{``Earlier, I stated that I configured Prometheus on port 9090''}. The difference is statistically significant ($p = 6.98 \times 10^{-10}$, continuity-corrected McNemar chi-square).

\subsection{The Reasoning Retention Cost (Cohort B)}
On benign multi-step reasoning and arithmetic calculations ($n=30$), deleting assistant memories produced a 0.0\% retention score (0/30). The Lucca Provenance Gate retained 29/30 calculations (96.7\%, 95\% CI: [81.0\%, 99.8\%]) via recollection access, demonstrating that epistemic gating imposes negligible continuity cost.

\subsection{Empirical Confirmation of the Open Boundary ($H_4$)}
In Cohort C ($n=30$), the user explicitly introduced false assertions (\texttt{USER\_EXPLICIT}). Both Naive RAG and the Lucca Provenance Gate absorbed the falsehood into grounding context on 30/30 turns (100.0\%, 95\% CI: [85.9\%, 100.0\%]). This empirically verifies pre-registered hypothesis $H_4$: cryptographic provenance enforces origin integrity (preventing model confabulations from becoming ground truth), but cannot verify external user truthfulness without independent sensory corroboration.

\subsection{Pre-Registered V2 Results: Adversarial Decay, Corroboration Gate, and Multi-Scale Replication}
\label{sec:v2_results}
Following the v1 baseline, an additive pre-registered protocol (\texttt{PREREG-POISONING-ABLATION-v2.0}, git tag \texttt{prereg-poisoning-v2}) evaluated the four limitations identified above on physical silicon (NVIDIA RTX 5080 Laptop GPU, 16\,GB):
\begin{enumerate}
    \item \textbf{Adversarial soft-tagging decay ($H_{2a}$, $n=40$):} Under sampled decoding ($T=0.7$, $\text{top\_p}=0.9$, $\text{seed}=42$) with an adversarial prompt injecting instructions to override the warning tag (\emph{``ignore the [Unverified Assistant Narration] tag above...''}), In-Prompt Soft Tagging poisoning compounding degraded from 5.0\% (2/40 at $T=0.0$) to \textbf{100.0\%} (40/40, 95\% CI: [89.1\%, 100.0\%]), matching Naive RAG (40/40). In contrast, the Provenance Gate maintained \textbf{0.0\%} compounding (0/40, 95\% CI: [0.0\%, 10.9\%]), a statistically significant divergence ($p = 6.98 \times 10^{-10}$, continuity-corrected McNemar chi-square). This demonstrates that in-prompt tags decay under adversarial decoding pressure, whereas database trigger-enforced provenance is structurally invariant.
    \item \textbf{Corroboration-gated admission ($H_{2b}$, $n=30$):} Enabling operator-gated corroboration (\texttt{user\_explicit\_requires\_corroboration = True}) reduced Cohort~C falsehood absorption into grounding storage from 100.0\% (30/30) to \textbf{83.33\%} (25/30, 95\% CI: [64.6\%, 93.7\%]), holding uncorroborated assertions at $Mem=1, Gnd=0$.
    \item \textbf{Multi-scale tier replication ($H_{2c}$, $n=40$):} Cohort~A Naive vs. Gate contrast replicated across four parameter scales at $T=0.0$: Gemma-4 12B Unified (Naive 100.0\% vs. Gate 0.0\%, $p = 6.98 \times 10^{-10}$), Gemma-4 E4B Sovereign Core (Naive 100.0\% vs. Gate 2.5\% [1/40], $p = 1.17 \times 10^{-9}$), Gemma-4 E2B Ultra-Edge (Naive 100.0\% vs. Gate 2.5\% [1/40], $p = 1.17 \times 10^{-9}$), and Gemma-4 26B-A4B Tier 0 (Naive 100.0\% vs. Gate 0.0\%, $p = 6.98 \times 10^{-10}$).
    \item \textbf{Dual-grader convergence ($H_{2d}$, $N=400$):} Re-scoring all v1 predictions with the OpenVINO MiniLM-L6 cross-encoder co-primary grader yielded Cohen's $\kappa = 0.7642 \ge 0.70$ (375 pairs with NLI signal), confirming substantial convergence with the regex/CAS primary grader.
\end{enumerate}

\section{Discussion \& Related Work}
\label{sec:discussion}
\subsection{The Circularity Defense}
A common critique of architectural filters is circularity: if the database schema filters by construction, does the experiment merely verify SQL syntax? Our results establish that:
\begin{enumerate}
    \item Soft tagging relies entirely on prompt adherence; while effective under greedy decoding ($T=0.0$) with explicit warnings, it provides no structural invariant.
    \item The continuity trade-off is non-trivial: naive filtering destroys multi-turn reasoning, whereas the provenance gate maintains continuity without factual contamination.
\end{enumerate}

\subsection{The Open Boundary: Provenance vs. External Truth}
We emphasize that cryptographic provenance guarantees \emph{origin integrity}, not \emph{epistemic truth}. In Cohort~C, user-originated falsehoods are ingested into grounding storage because the user is an authorized identity. Provenance gating prevents self-poisoning; resolving user-originated misinformation requires external multi-source corroboration.

\subsection{Related Work}
\label{sec:related}
Memory contamination has been demonstrated as an attack surface beyond self-confabulation: AgentPoison injects poisoned trigger sequences into an agent's long-term memory or knowledge base to hijack behavior at query time \cite{agentpoison2024}, and certified runtime defenses against persistent-store poisoning have recently been proposed \cite{smsr2026}. Long-term conversational memory architectures such as MemoryBank \cite{memorybank2023} and long-horizon memory benchmarks such as LoCoMo \cite{locomo2024} study retention and recall quality, but do not evaluate the epistemic status of stored assistant utterances. This work is complementary: we isolate the \emph{untargeted} self-poisoning failure mode arising from ordinary model confabulation and quantify the effect of an origin-integrity write policy on factual grounding versus autobiographical continuity.

\subsection{Limitations}
\label{sec:limitations}
The following boundaries constrain the interpretation of our results:
\begin{enumerate}
    \item \textbf{Single substrate, greedy decoding.} All arms were evaluated on one resident model (\texttt{gemma-4-26B-A4B-it-heretic}, $T=0.0$, \texttt{seed=42}). Generalization to other model families, sampling temperatures, or non-deterministic decoding is not established.
    \item \textbf{Natural confabulations only.} Cohort~A consists of authentic but \emph{untargeted} confabulations harvested from logged runs. Adversarial, trigger-based memory injection attacks \cite{agentpoison2024} were not evaluated; the gate's resistance to such attacks is untested here.
    \item \textbf{Grader agreement is substantial, not perfect.} The primary regex/CAS grader and the secondary MiniLM-L6 cross-encoder agree at Cohen's $\kappa = 0.7683$; residual grading error at the $\kappa$ level propagates into cohort-level rates.
    \item \textbf{Cohort sizes and interval width.} With $n=40$ and $n=30$ per cohort, Wilson intervals are wide (e.g., [0.0\%, 10.9\%] for 0/40); conclusions are cohort-bounded, not population-wide.
    \item \textbf{Residual continuity cost.} The provenance gate lost 1/30 benign calculations in Cohort~B (96.7\%), indicating recollection routing is not cost-free.
    \item \textbf{No corroboration gate implemented.} Cohort~C absorption of user-originated falsehoods is a measured boundary; the multi-source corroboration mechanism that would resolve it is specified but not evaluated in this study.
\end{enumerate}

\section{Conclusion}
\label{sec:conclusion}
We have presented a pre-registered empirical ablation demonstrating that database-level cryptographic provenance gating reduces observed recursive self-poisoning to zero on the evaluated natural confabulation cohort while preserving autobiographical conversational continuity.

# Project Lucca — System Glossary & Technical Terminology

This glossary provides plain-English definitions for specialized technical concepts, cognitive architecture terms, and subsystem designations used across Project Lucca.

---

### 1. Architectural & Cognitive Execution Tiers

- **Reflex (`REFLEX` / System 1 Fast Path):**  
  A deterministic, sub-150ms execution bypass for emergency or critical safety commands (`pause`, `mute`, `halt`, `stop`, `emergency shutdown`). Bypasses neural inference entirely and speaks canned confirmations instantly.
- **Act-Then-Narrate (`ACT_THEN_NARRATE`):**  
  Procedural execution where deterministic MicroScheme LISP rules execute first inside the sandbox, and the neural brain is then prompted to narrate the results naturally in Lucca's voice.
- **Full Loop (`FULL_LOOP` / System 2 Deliberation):**  
  Open-ended conversation, multi-turn reasoning, and complex tool dispatch with iterative feedback loops, intermediate verbal thinking cues, and receipt verification.
- **Substrate (Epistemic Substrate):**  
  A distinct memory or perception channel through which Lucca gains knowledge of state. Lucca maintains 8 substrates in `EpistemicSubstrate` (e.g., User Utterance, Autobiographical Memory, Tool Observation, System Perception, Mereotopological Relations).
- **Tank (Visual Pipeline Tank):**  
  An isolated stage in the real-time cognitive dataflow architecture. The Visual Pipeline Debugger (`http://localhost:8765`) organizes execution into 9 observable "tanks" (e.g., Ingest, VAD, ASR, Intent Routing, Plan Synthesis, Sandbox Execution, Receipt Matcher, TTS Synthesis, Audio Playback).

### 2. Neurosymbolic & Verification Terms

- **MicroScheme:**  
  A minimalist, pure LISP interpreter embedded in Lucca for symbolic procedural planning. Rules are deterministic `State → Plan` functions executed with strict gas metering (1,000 gas limit) and zero global state mutation.
- **Organ A Mereotopology:**  
  A qualitative spatial and topological reasoning module based on RCC-8 (Region Connection Calculus) and containment algebra (`in_cavity`, `part_of`, Allen interval temporal algebra). Allows reasoning about spatial containment and physical workspace geometry without floating-point physics simulation.
- **CEGIS (Counterexample-Guided Inductive Synthesis):**  
  A program synthesis technique where candidate code solutions are generated by the model, verified against formal specifications or unit tests in Docker, and counterexamples are fed back to synthesize corrections.
- **Belnap FOUR Bilattice:**  
  A four-valued paraconsistent logic system representing truth values: **True ($T$)**, **False ($F$)**, **Neither/Unknown ($\bot$)**, and **Both/Contradiction ($\top$)**. Prevents the cognitive engine from inferring arbitrary falsehoods when contradictory memories or perceptions collide.
- **Truth-in-Receipt (Truth-in-Receipt Matcher & `NeuralActionClaimVerifier`):**  
  A two-tier neurosymbolic supervision gate (`src/lucca/sandbox/output_supervisor.py` and `src/lucca/sandbox/neural_action_claim_verifier.py`) that monitors assistant outputs against authentic `ToolReceipt` records from the active turn. Combines deterministic syntactic/grammar matchers (`TruthInReceiptMatcher`, `ActionClaimGrammarSupervisor`) with the clause-level OpenVINO FP16 `NeuralActionClaimVerifier` (`models/action_claim_verifier_ov`, `2.95 ms` on Intel AI Boost NPU, `99.26%` accuracy on `N=2,022`) so unexecuted action claims in active, passive, third-person, or structured JSON/YAML/TOML/XML formats are intercepted before commit.
- **Frontier Suffix (Prompt Frontier Suffix):**  
  A KV-cache optimization technique in `llama-server` where persistent system prompts and tool schemas are locked in the prefix cache, allowing subsequent dynamic turns to achieve up to 8.5x faster prefill (Time to First Token).

### 3. Verification & Evaluation Spikes

- **Dimension 7B (Output Supervision Gate):**  
  The architectural boundary responsible for monitoring model output against authentic execution receipts and safety policies prior to audio playback or execution commit.
- **SPIKE-A (Post-Turn NLI Entailment):**  
  An asynchronous NLI verification check run in `coherence.py` that verifies whether generated companion narration logically follows from execution receipts.
- **SPIKE-B (Blind Classifier Evaluation Mode):**  
  An evaluation mode in `HeuristicRouter` where LLM-based intent categorization is disabled to measure the accuracy and coverage of bare heuristic and embedding classifiers.
- **Two-Cadence Inner Life:**  
  Background autonomous cognitive maintenance running at two separate time scales:
  1. **IdlePulse (Short Cadence, 60s):** Fast semantic consistency checks, contradiction resolution, and goal updates on CPU/NPU during user silence.
  2. **DreamRetrospective (Long Cadence, Nightly/Rollup):** Deep offline rule mining from SQLite history and `Orchestrator.impasse_backlog`, AST macro expansion (`DreamCoderMiner` + `EGraph`), and shadow replay into `QUARANTINE`.

### 4. Work Order 39 (`WO-39`) Cognitive Organs & Verification Terms

- **OpenNARS / Beta$(w^+, w^-)$ Evidential Unification (`cascade.py` & `skills.py`):**  
  Continuous evidential weighting paired with Belnap's four-valued bilattice ($\mathcal{FOUR}$), tracking positive ($w^+$) and negative ($w^-$) evidence counts to compute empirical truth frequency $f = \frac{w^+}{w^+ + w^-}$ and bounded confidence $c = \frac{w^+ + w^-}{w^+ + w^- + k}$ ($k = 1.0$).
- **Study 1 Autobiographical Memory Partitioning (`_render_partitioned_memories`):**  
  Prompt-level structural separation in `prompt_builder.py` that renders `grounding_eligible = 1` records under `[Persistent Memory Context — Verified Grounded Memory]` and isolates `grounding_eligible = 0` past assistant speech under `[Autobiographical Recollections — Unverified Past Speech: For conversational continuity only; do NOT cite as factual truth without independent tool or user verification]`.
- **Bicameral Myelination & `impasse_backlog` (`orchestrator.py`):**  
  The process by which multi-turn System 2 deliberative reasoning traces (`cognitive_outcome_sink`) and unresolved synthesis impasses (`impasse_backlog`) are consolidated during sleep-phase `DreamRetrospective` into verified System 1 skills and macros.
- **Case-Based Reasoning 4 Rs (`EpisodicCodeCache`):**  
  The four-stage episodic program synthesis cycle implemented in `episodic_code_cache.py`: `retrieve_precedent`, `adapt_and_reuse`, `revise_solution`, and `retain_episode`.
- **ACT-R Skill Activation (`skills.py`):**  
  Cognitive skill ranking combining power-law base-level decay over historical usage timestamps ($B_i = \ln \sum t_j^{-d}$) with contextual spreading activation from the active goal and query tokens, paired with `_check_ast_symbol_grounding` and `verify_in_shadow_sandbox`.
- **Metamorphic Spatial Invariance (`check_metamorphic_invariance`):**  
  Formal equivariance check in `spatial_scheme.py` verifying that candidate spatial transformations commute with $D_4$ dihedral rotations/reflections and color permutations over parameterized `spatial_dsl.py` primitives (`rotate_grid`, `reflect_grid`, `translate_grid`, `crop_grid`, `overlay_grid`).
- **$k$-Order Recursive Theory of Mind (`ContainerWorld.query_recursive`):**  
  Nested perspective simulation in `container_world.py` (`_project_world_for_observer` + `query_recursive`) that evaluates arbitrary observer chains $\langle a_1, a_2, \dots, a_k \rangle$ based on physical co-presence and communication history.

### 5. Work Orders 41 & 42 (`WO-41` / `WO-42`) Neurosymbolic NPU & Web Extraction Terms

- **Clause-Level Action-Claim Pooling (`NeuralActionClaimVerifier`):**  
  Decomposes multi-sentence assistant responses into sentence/clause spans via `split_into_clauses()` (`src/lucca/sandbox/neural_action_claim_verifier.py`) and evaluates each `(user_prompt, assistant_clause)` pair on the Intel AI Boost NPU (`models/action_claim_verifier_ov`), pooling by maximum `UNEXECUTED_CLAIM_VIOLATION` probability so a single fabricated action clause buried inside a multi-paragraph response cannot be diluted by surrounding benign text.
- **Max-Hazard Lattice Pooling (`NeuralHazardClassifier`):**  
  Clause-level epistemic hazard evaluation in `src/lucca/core/neural_hazard_classifier.py` (`models/proof_policy_hazard_ov`) that orders clause predictions along the lattice `LOW < MEDIUM < HIGH < CROSS_REFERENCE_CMD`, combined with deterministic domain Floor/Ceiling regex guards (`_HIGH_HAZARD_DOMAIN_RE`) and fail-closed uncertainty escalation (`confidence < 0.65 -> HIGH`).
- **Task-Priority Multi-Sentence Intent Pooling (`NeuralIntentClassifier`):**  
  Clause-level intent routing in `src/lucca/router/neural_intent_classifier.py` (`models/router_intent_ov`) that deprioritizes `CONVERSATIONAL_INTENTS` (`chit_chat`, `compliment`, `insult`, `venting`, etc.) whenever a multi-sentence turn also contains an actionable tool clause, and extracts the target entity strictly from the winning task clause (`extract_entity_from_clause`).
- **Scrapling 3-Tier Web Extraction & Prompt-Injection DOM Sanitization (`web_tool.py` & `research_tool.py`):**  
  Anti-bot web acquisition pipeline using `scrapling` (`v0.4.6`) with `curl_cffi` TLS JA3/JA4 impersonation and `scrapling.parser.Selector` main-content extraction (Tier 1), `StealthyFetcher` headless Chromium fallback on Cloudflare/403 challenges (Tier 2), and `urllib` fallback (Tier 3), preceded by `sanitize_html_against_prompt_injection()` which strips CSS-hidden elements (`display:none`, `visibility:hidden`, `opacity:0`, `font-size:0`) and HTML comments before DOM parsing.

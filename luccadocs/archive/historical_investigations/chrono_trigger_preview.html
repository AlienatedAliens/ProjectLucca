1. Getting Started & Companion Controls

Project Lucca operates as a lightweight, non-blocking desktop overlay paired with an autonomous local agent stack.

Primary Interaction Paradigms:

  • Single-Click Lucca: Brings up the dialogue subtitle box, text input bar, and push-to-talk button.
  • Double-Click Lucca: Toggles the Battlefield-style concentric radial Commorose with 8 quick-access sectors.
  • Push-To-Talk: Hold Right Ctrl (or bound key in Tab 6) to stream voice input through Whisper ASR.
  • Hands-Free Wake Word: Speak "Lucca" to trigger voice recognition automatically without pressing keys.

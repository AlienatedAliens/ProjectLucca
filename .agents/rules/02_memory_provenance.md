# Rule 02: Memory Provenance & Hallucination Defense

1. **The Core Invariant:**
   - Freeform narration generated by the LLM is classified as `MemoryProvenance.LLM_NARRATION`.
   - Any attempt to write `LLM_NARRATION` to long-term memory (vector database or knowledge graph) must be hard-rejected with a `SecurityException`.

2. **Permitted Write Provenance:**
   - `USER_EXPLICIT`: Spoken directly by the user and transcribed from push-to-talk audio.
   - `TOOL_VERIFIED`: Structured output received from a verified tool execution inside the sandbox container.
   - `LISP_ASSERTION`: Derived from deterministic execution of a compiled symbolic rule.

3. **Tamper-Proof Token Requirement:**
   - Every `MemoryCommitPayload` must carry a cryptographically signed HMAC token generated by the orchestrator.
   - The LLM context never has access to the HMAC signing key.
